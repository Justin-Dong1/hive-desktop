# 安装版验收记录

## 1.1.5 安装器选项（2026-10-18）

- 新安装时由用户勾选是否创建桌面快捷方式，默认勾选；不创建也可从开始菜单启动。
- 覆盖升级也显示相同选项，并按用户当次选择保留或删除桌面快捷方式。
- 正常卸载先恢复 Windows 桌面，再询问保留个人数据还是彻底删除。
- “彻底删除”清理 `%APPDATA%\glass-hive-desktop` 和 `%LOCALAPPDATA%\GlassHiveDesktop`；默认及静默卸载均保留数据，避免误删。
- 安装完成后主动清理 electron-builder 的 `%LOCALAPPDATA%\glass-hive-desktop-updater\installer.exe` 缓存，不在 C 盘保留第二份安装包。浏览器下载的原始 Setup.exe 不属于应用数据，安装器不会擅自删除用户下载文件。
- 38 项回归测试通过；仍需在独立 Windows 用户环境人工核对安装页面、两个卸载分支和重装恢复。

## 自测命令

```powershell
pnpm run check
node tools/test-first-run.js
node tools/test-wallpaper-optional.js
node tools/test-recovery-order.js
node tools/test-layout-store.js
node tools/test-note-recovery.js
```
