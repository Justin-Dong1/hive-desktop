# 当前源码更新记录（未打包发布）

更新日期：2026-10-20。版本字段仍为 1.1.5；本页描述 `main` 的后续开发改动，不代表现有 `v1.1.5-beta.1` 安装附件已经更新。下一次安装包应从新的干净提交构建，并单独核对清单、哈希及安装流程。

## 新增功能

- 面板新增“时钟”页：一次性闹钟、倒计时、计时；闹钟与倒计时可附提醒文字，支持删除，倒计时支持暂停/继续。
- 时钟本机保存、多屏共享；运行期间使用单调时间处理时长，区分日期时间闹钟与持续时间计时，处理时间调整、休眠及重启后的到期提醒。
- 音乐页新增“电脑音量”滑块，控制 Windows 默认播放设备主音量，保留原静音状态；请求串行化、拖动合并、设备失败提示。

## 桌面恢复与启动修复

- 隐藏原生图标前等待渲染器、桌面挂载和守护就绪；就绪请求合并，并按窗口重建代次丢弃过期结果。
- 检查 Explorer 桌面宿主，处理 Wallpaper 引起的宿主变化；窗口销毁、未挂载或没有窗口时不再跳过检查，优先恢复原桌面。
- 守护进程与主进程健康检查，保留睡眠/调度间隔宽限期；恢复记录包含所属进程，Apply/Restore 加互斥，防止旧守护误操作新实例。
- 新增当前用户的独立计划任务兜底，即使主进程和守护同时退出，也可检查遗留恢复记录。疑似存活但卡死的实例需两次间隔检查，恢复并非即时。
- 新增实际存活状态检查，避免仅依赖旧 `ready:true` 文件；重复启动可请求检查桌面宿主。
- 源码启动器优先使用首次设置的用户 Wallpaper 配置，项目配置仅作兼容回退，明确关闭的用户选择不会被旧配置覆盖。
- 布局备份支持新增时钟页选择值，避免新增页状态导致布局备份校验冲突。时钟内容不包含在布局备份里。
- 卸载脚本尝试移除属于当前安装目录的恢复任务，不移除其他安装目录所拥有的任务；本批卸载变更尚未重新编译及交互验收。

- 在开发机受控结束蜂巢主进程与守护进程后，独立任务恢复原生图标并清除系统恢复状态；重新启动后两个屏幕报告就绪。
- 布局与便签文件测试前后 SHA-256 一致；个人哈希、路径、日志和数据不随源码发布。
- 故障策略隔离测试覆盖旧所属进程、健康心跳、两次观察宽限、卡死判定、唤醒恢复和无可用窗口。

测试结果是本机与自动化场景证据，不等于所有 Windows 环境均通过。
