# 1.1.2 测试版

本次以当前桌面源码为基准，不使用旧 1.1.0/1.1.1 安装包替代。

- 内圆使用原图颜色，去除透明边距后裁圆，不添加白底；保留原图形态可单独选择。
- 内外圆固定同心；悬停上浮 5px，按下回压，拖拽暂停动画，支持系统减少动态效果设置。
- Wallpaper 分别查询 32/64 位完整进程名，修复 tasklist 通配符导致误判未运行。
- 频谱不再依赖 Wallpaper；组件内置，首次设置说明显示条件。
- Wallpaper 向导显示保存路径与运行检测结果，未确认启动时明确提示而非静默忽略。
- README 将普通用户的下载、替换与选择步骤和开发者编译说明分开。

## 一致性保障

构建必须从已提交且干净的源码目录运行；打包后逐文件比对运行源码及资源，清单记录提交号与 SHA-256。安装版 `--package-smoke` 使用独立临时用户目录，对清单内文件逐一核验并执行真实频谱自测，不接管桌面。

本次不能保证任意播放器、所有显卡/显示缩放组合和不同电脑均无问题。新用户不包含开发者的私人便签、布局与桌面文件；安装版与源码版个人设置相同且共用原用户目录时，应保持既有布局。无需也不会复制开发者私人配置给新用户。

安装包仍未代码签名，保持 Release 草稿/测试版，不宣称完成真实重启、所有多屏热插拔或跨版本回退验收。
