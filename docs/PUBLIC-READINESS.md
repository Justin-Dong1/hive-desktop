# 公开前检查与待办

日期：2026-10-17。本记录不是完整安全审计或法律意见。

## 已完成

- 原创代码采用 GPL-3.0-only；NAudio.Core / NAudio.Wasapi 2.2.1 使用 MIT 许可，旧 NAudio 1.10 不进入当前安装包。
- Git 可达历史使用 GitHub 隐私邮箱；跟踪文件未发现私人邮箱、个人绝对路径、访问令牌或私钥。
- Electron 从 39.8.10 升级到 44.8.0，`pnpm audit --audit-level=high` 通过，不再包含高危告警。
- 桌面与便签窗口启用沙箱和上下文隔离、关闭 Node.js 集成、禁止新窗口与页面导航，并配置内容安全策略。
- 37 个测试脚本通过，包括布局、便签、恢复顺序、Wallpaper 可选路径、媒体、频谱、窗口安全、图标同心和真实 Chromium 悬浮动画测试。
- 频谱使用 WASAPI 回环分析系统播放声音，不采集麦克风、不上传音频。
- GitHub Release 构建必须来自干净提交，包内清单绑定版本、提交号和逐文件 SHA-256；最终安装包另附 `SHA256SUMS.txt`。

完整依赖审计仍报告一个来自 `electron-builder` 构建链的中危 `sprintf-js` 项，当前没有上游修复版本。该依赖用于开发机打包流程，不进入蜂巢桌面运行资源；高危级别审计已作为 CI 阻断条件。

## 发布版必须执行

1. 从干净提交构建新版本，不复用任何旧安装附件。
2. 对安装包、校验文件和包内清单执行上传后回下载验证；结果与 SHA-256 记录在对应 GitHub Release 正文。
3. 仅发布当前版本的预发布草稿。旧 1.1.0 / 1.1.2 / 1.1.3 草稿不得作为最新版本发布。
4. 仓库公开后启用 `main` 分支保护，并让 Windows CI 成为合并前检查。

## 仍需真实设备验收

- 首次安装、自定义路径、首次设置和桌面/开始菜单入口。
- 同版本与跨版本覆盖升级。
- 正常退出、异常恢复、卸载及卸载恢复失败分支。
- 真实重启和登录自启动后的布局、便签保留。
- 无 Wallpaper Engine 的独立电脑，以及 Wallpaper 安装在不同路径的电脑。
- 多显示器、不同缩放比例、热插拔、休眠恢复、真实中文输入法和不同播放器。

安装包尚未进行 Windows 代码签名。测试版可以在明确披露后分发，但不得要求用户关闭系统安全防护；稳定版发布前建议完成签名与上述交互验收。

## 公开仓库配套

- `SECURITY.md` 提供私密漏洞报告说明。
- GitHub Issue 模板要求系统版本、显示环境、复现步骤和脱敏材料。
- Windows CI 执行锁定依赖安装、语法检查、高危依赖审计、原生资源准备、37 项测试和安装目录组装检查。
