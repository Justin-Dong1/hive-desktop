# 1.1.5 安装测试版

本版本沿用 1.1.4 的功能、安全加固与数据格式，改进安装和卸载体验。

- 安装向导新增“在桌面创建蜂巢桌面快捷方式”选项，默认勾选。
- 取消勾选后不创建桌面快捷方式，仍可从开始菜单启动。
- 卸载时可选择保留个人布局、便签、备份和自定义图标，或彻底删除全部个人数据与图标缓存。
- 覆盖升级始终保留个人数据，安装向导会再次询问是否保留桌面快捷方式；升级过程不会出现删除个人数据的提示。
- 安装完成后会清理 electron-builder 的本地安装器缓存，不在 `%LOCALAPPDATA%\glass-hive-desktop-updater` 保留第二份 Setup.exe；浏览器下载目录中的原始安装包可由用户自行删除。

Wallpaper Engine 仍为可选软件，频谱组件已经内置。本版本仍是未签名 Pre-release，安装前请核对 `SHA256SUMS.txt`。

## 验证范围与已知限制

安装器已成功编译，38 项回归检查和程序隔离自检通过；其中安装选项测试仅检查脚本内容。首次安装、覆盖升级、两个卸载分支及重启流程尚未完成独立环境交互验收。

- 安装版与源码版共享个人数据。选择“彻底删除”也会删除源码版的布局、便签和备份；仍需数据时请选择“保留”并提前备份。
- 删除目录后尚未检查结果，文件被占用时可能残留，当前没有明确清理失败提示。
- 返回上一页再进入快捷方式选项页，会恢复默认勾选；继续安装前请重新确认。

详细记录见 [安装版验收记录](INSTALLER-TESTING.md)。
