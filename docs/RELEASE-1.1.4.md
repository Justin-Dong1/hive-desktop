# 1.1.4 安装测试版

本版本在 1.1.3 的功能与数据兼容基础上完成公开前安全升级。

- Electron 从 39.8.10 升级到仍受支持的 44.8.0，依赖审计不再包含高危项。
- 桌面窗口和便签窗口明确启用沙箱、上下文隔离并关闭 Node.js 集成。
- 禁止渲染窗口自行打开新窗口或导航到其他页面；桌面与便签页面均配置内容安全策略。
- 图标悬浮测试显式覆盖正常动画与 Windows“减少动画”偏好，避免环境差异造成误判。
- 新增统一回归测试入口、Windows CI、安全报告策略和问题模板。
- 继续使用 MIT 许可的 NAudio 2.2.1 Core / WASAPI 模块，不包含旧 NAudio 1.10。

普通用户只需安装 `HiveDesktop-Setup-1.1.4-x64.exe`。Wallpaper Engine 是可选软件，频谱组件已经内置。

本版本仍作为未签名测试版发布。请在安装前核对 `SHA256SUMS.txt`；未完成的真实设备验收范围见 `docs/INSTALLER-TESTING.md`。
