# 蜂巢桌面 1.1.6 · 安装测试版

Windows x64 安装包，内置 Electron 和频谱依赖，无需另外安装 Node.js/pnpm。Wallpaper Engine 可选，不含壁纸文件。

## 本次更新

- 新增时钟页：闹钟、倒计时、计时，以及自定义提醒文字。
- 音乐页新增 Windows 默认播放设备主音量控制，保留静音状态。
- 加固桌面就绪、宿主监测、退出恢复及旧守护与新实例之间的隔离。
- 恢复计划任务改为无控制台入口，没有遗留恢复状态时不创建 PowerShell 进程；尊重手动停用状态，不会在启动时自动重新启用。
- 修复 PowerShell 5.1 读取 UTF-8 中文路径时误判进程身份，避免源码启动器约 85 秒后错误关闭蜂巢。
- 源码启动器与首次设置共用 Wallpaper 用户配置，旧项目配置仅作兼容回退。

## 安装与数据

下载 `HiveDesktop-Setup-1.1.6-x64.exe`，先退出旧蜂巢，备份 `%APPDATA%\glass-hive-desktop`，再运行安装包。请核对附件 `SHA256SUMS.txt`；源码提交与包内文件哈希见 `release-manifest.json`。

安装时可选桌面快捷方式；首次设置可选登录启动和 Wallpaper 联动。没有 Wallpaper 也能使用。此前手动停用的恢复任务会继续保持停用，进程守护仍保留，但没有计划任务独立兜底。

## 验证范围及限制

- 本地 49 个回归测试脚本通过，包含真实 PowerShell 5.1 中文路径及 Windows Script Host 隔离测试。
- 修复后正常启动返回 ready，双屏就绪，受测进程运行超过原 85 秒误退出点。
- 安装包构建、隔离运行自检、上传与回下载验证结果以发布正文补充记录为准，不能仅凭本文件认为已完成。
- 未进行 Windows 代码签名。首次安装、覆盖升级、卸载分支、真实重启/休眠/热插拔仍需独立环境验收，保持测试版，不宣称稳定版。
- 计划任务新入口在本机仍保持原停用状态，尚未完成重新启用后的实际闪屏观察。Windows Script Host 被组织策略禁用时该入口可能无法运行。
- 原有安装器限制仍存在：源码与安装版共享个人数据，彻底删除会影响两者；删除结果未检查；返回快捷方式选项页可能重置勾选。
- 闹钟不会在程序退出或电脑关闭时响铃，也不会唤醒睡眠中的电脑；通知受系统设置影响。网易云弹窗悬停消失仍未确认根因。

详细使用方法见仓库 README，测试边界见 `docs/INSTALLER-TESTING.md`。不要关闭系统安全防护以绕过安装警告。
